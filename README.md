# Physics Informed Neural Networks (PINN) implementation for Ordinary Differential Equations (ODE's)
This repository implements a Physics Informed Neural Network to resolve Ordinary Differential Equations (ODE's) that have both a closed and unclosed solutions form. 

## What is a PINN? 
Also referred to as a Theory-Trained NN, it is a universal approximator that is embedded with the physical laws that govern a certain set of data. 

Primarily used to resolve PDE's, we have focused on implementing the PINN's on basic ODE's to gather an understanding of how the Loss Function behaves and later apply it towards the resolution of much more complex DE's and PDE's.
